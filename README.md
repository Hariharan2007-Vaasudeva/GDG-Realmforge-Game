# 🏰 RealmForge – Fantasy Character Generator

### GDG Build Project

RealmForge is a fantasy-themed character creation experience where users can explore and create unique fantasy characters through an interactive web interface.

The project focuses on bringing imagination into a simple and engaging digital experience, combining creative character concepts with a modern interface.

- Designed to make fantasy character creation engaging and accessible.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

- Node.js
- npm

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/Hariharan2007-Vaasudeva/GDG-Realmforge-Game.git
   ```

2. Navigate to the project folder:

   ```bash
   cd GDG-Realmforge-Game
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the root directory and add your Gemini API key:

   ```env
   GEMINI_API_KEY=your_api_key
   ```

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL shown in your terminal.
